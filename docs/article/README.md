# Article figures

The diagrams used in the write-up that accompanies this project ([Routing Kubernetes Traffic to Localhost Without Extra Dependencies](https://medium.com/@bilgihankose)). PNGs are rendered at 2800×1600 from the SVG sources next to them, so they stay editable.

They are kept here so the article can reference stable URLs, and so the figures outlive whatever platform the article lives on.
